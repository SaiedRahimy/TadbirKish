# 🧩 Tadbir Kish Vira - Test Project

## 📘 Overview

This project was developed as a **technical test project** for the interview with **Tadbir Kish Vira**.  
The goal is to design and implement a simple system for **managing insurance coverages**, including registration and retrieval operations.

---

## ⚙️ Features

- Define a list of **insurance coverages**
- Each coverage has a **valid amount range** (minimum and maximum)
- The user can select one or multiple coverages and submit them
- During submission, **validations** are performed:
  - If any selected coverage amount is out of range → an error is returned
  - If all values are valid → the data is stored successfully
- The user can also **retrieve the list of coverages** through another API endpoint

---

## 🧠 Technologies Used

- **ASP.NET Core 8 (Web API)**
- **Entity Framework Core**
- **SQL Server**
